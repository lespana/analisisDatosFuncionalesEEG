## Opciones habituales

| Licencia | Para | Efecto |
|---|---|---|
| MIT | código | Uso libre con atribución; muy permisiva. |
| BSD-3-Clause | código | Como MIT, y además prohíbe usar el nombre de la autora para promocionar derivados. |
| GPL-3.0 | código | Los derivados que se distribuyan deben conservar la misma licencia. |
| CC BY 4.0 | texto y figuras | Reutilización con atribución. |

Una combinación común en repositorios académicos es MIT o BSD-3-Clause para el código y CC BY 4.0 para documentos y figuras, siempre que la institución lo permita.

Para agregarla en GitHub: *Add file → Create new file*, escriba `LICENSE` como nombre y use *Choose a license template*.
